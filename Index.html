Akun & perangkat

Patroli offline tersedia selama aplikasi tetap terbuka. Membuka ulang URL GAS membutuhkan jaringan. Draft disimpan di IndexedDB; penghapusan data situs, mode privat, pergantian browser, atau penyimpanan penuh dapat memengaruhi ketersediaannya.

Akses di layar utama

Buka URL deployment di browser. Gunakan Add to Home Screen / Tambahkan ke layar utama bila tersedia. Ini akses pintas; versi HTML Service ini tidak menyediakan instalasi PWA penuh atau pembukaan ulang offline.

Dokumentasi titik

Foto dari kamera atau galeri, lalu jelaskan kondisi di lokasi.

Tambahkan hingga 8 foto per titik. Kamera dapat digunakan berulang, galeri mendukung pilihan beberapa foto.

Jika darurat, hubungi pihak terkait sesuai SOP hotel; jangan menunggu unggah laporan.
